# E-Commerce Analysis Dashboard (Ms. Power BI)
This dashboard is my **fifth self-directed learning project.** I created it to **improve my data analysis skills,** using Microsoft Power BI as a data visualization tool. The **dataset** used comes from **Kaggle** and consists of 51,304 purchase transactions **(51,304 rows),** with prices listed in USD ($). 

This dashboard is titled **“E-Commerce Analysis Dashboard”** and its purpose is to analyze purchasing trends in online markets across several countries, including the United States, Australia, France, Mexico, Germany, and others. Using DAX (Data Analysis Expressions), I calculated the key performance indicators (KPIs) defined at the outset, such as Total Revenue, Total Profit, Profit Margin (%), Total Transactions, Average Order Value, as well as purchasing trends such as Monthly Sales Trends, Best-Selling Products, and the top countries and product categories that have contributed significantly to sales over the two-year period.
